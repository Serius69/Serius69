## 📐 Por qué ARIMA y Monte Carlo

Dos modelos que uso recurrentemente y que definen mi enfoque:

**ARIMA** para el dólar paralelo boliviano porque:
- El mercado paralelo tiene baja liquidez → alta autocorrelación en la serie
- Identificar órdenes p, d, q óptimos con test ADF + análisis ACF/PACF
- Ventana de predicción de 2 semanas justificada por la volatilidad real del mercado

**Monte Carlo** para proyección de demanda en PYMEs porque:
- Las series históricas cortas hacen que una regresión puntual sea poco confiable
- Las distribuciones probabilísticas son más honestas que una predicción única
- Los tomadores de decisión necesitan rangos de escenario (P10 / P50 / P90), no un número mágico
